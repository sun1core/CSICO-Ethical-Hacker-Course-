
1. mv - moves or renames files or directories
2. chomd - modifies files permissions
3. chown - change the ownership file
4. dd - copies data from an input to an output
5. pwd - displays the name of the current directory
6. ps - list the process that are currently running directories in the system 
7. su - simulates login as another user to be a superuser
8. sudo - runs a command as a superuser, by default, or another named user
9. grep - to search for specific strings of character within a file or command outputs
10. ifconfig - to display or configured network card information
11. apt-get  -  to install, configure, or remove packages on Debian and its derivatives
12. iwconfig - display the configure wireless network card related information
13. shutdown -  shut down the computer
14. passwd - to change password, for the current user
15. cat - to list the contents of a file and file name as the parameter
16. man - display the documentation for specific command
17. ls - displays the file inside directory
18. cd - change the current directory 
19. mkdir - creates directory  
20. cp - copies files and directory 
21. rm - removes files and directory 

*( . ) -  current directory  ( .. ) - parent directory*
*( > ) redirect the output of echo to a text file*
*( >> ) appends data to the end for the referred file, keeping the current contents intact*
*( -r ) recursive option must be used in rm or delete, all the files and directories inside a given directory are also deleted when deleting a parent directory*
